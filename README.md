# Restaurante Orígenes SV

Base inicial para el ERP/POS multisucursal del caso de negocio.

## Proyectos

- [`frontend/`](./frontend/README.md): React 19 + Vite + Reactstrap.
- [`backend/`](./backend/README.md): Express + Sequelize + SQL Server.

Cada proyecto es independiente y tiene su propio `package.json`, `.env.example`
y guía de instalación. Revisa los README de cada carpeta antes de ejecutar.

> Esta es una estructura de inicio: autenticación y operaciones de negocio no
> están habilitadas; consulta la documentación antes de usarla en producción.
